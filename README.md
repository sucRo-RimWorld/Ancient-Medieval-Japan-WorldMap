# Ancient & Medieval Japan - WorldMap / 中世日本ワールドマップ

**現状：1.6版Worldbuilder日本ワールド試作ソースを移管済み。新規機能開発は一時保留。** 作業再開の判断はAMJ Environmentの森林帯・中間温帯林・代表樹種の仕様確定後に行う。

RimWorld用の独立したオプション日本列島固定ワールド。利用には[Worldbuilder](https://steamcommunity.com/sharedfiles/filedetails/?id=3522102833)と[AMJ Environment](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Environment)が必要。現在の実証済み実装は**RimWorld 1.6のみ**、Steam Workshop未公開。
